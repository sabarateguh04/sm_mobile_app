## Matriks Role (Ringkas)

| role_id | Nama | Mode data | Sidebar utama |
|--------:|------|-----------|---------------|
| 1 | SuperAdmin | full (semua data) | Master referensi + Config SOTK |
| 2 | Admin Polda | territory (cakupan provinsi) | Admin menu + topbar |
| 3 | Admin Polres | territory (cakupan kab/kota) | Admin menu + topbar |
| 4 | Operator | own (CRUD data sendiri via `piket`) | Operator sidebar + topbar |
| 5 | Executive 3 (Polres) | view only | Sama operator, tanpa mutasi |
| 6 | Executive 2 (Polda) | view only | Sama admin Polda, tanpa mutasi |
| 7 | Executive 1 (Pusat) | view only | Sama admin pusat, tanpa mutasi |

**Registrasi mandiri:** default role = **Operator (4)** — `config/registration.php`, env `REGISTRATION_DEFAULT_ROLE_ID=4`.

### 2.2 Autocomplete Nama Jalan

Field **Nama Jalan** / **Lokasi** (`data-sbo-jalan-ac`) mengambil sumber dari **`t_datajalan`**, difilter menurut profil user:

| Profil USM | Cakupan autocomplete |
|------------|------------------------|
| Polres (`wilayah`) | Jalan yang pernah diinput user di Polres yang sama |
| Polda saja (`daerah`) | Jalan seluruh Polres di Polda tersebut |
| Polsek (`organisasi_daerah`) | Polsek + fallback Polres |

API: `GET /api/autocomplete/jalan`

> Bukan master jalan nasional — hanya riwayat input aplikasi. Kosong jika belum ada data di **Data Jalan**.

## Catatan Deploy & Migrasi

Setelah deploy ke production, jalankan:

```bash
php artisan migrate
php artisan config:clear
php artisan view:clear
php artisan optimize:clear
```

### Migrasi penting (periode QC)

| Migration | Fungsi |
|-----------|--------|
| `2026_06_09_120000_fix_master_territory_id_auto_increment` | AUTO_INCREMENT `master_provinsi`, `master_kabupaten_kota`, `master_territori` |
| `2026_06_09_130000_fix_org_suborg_primary_key_auto_increment` | AUTO_INCREMENT `org`, `suborg` |
| `2026_06_09_140000_fix_t_faktor_penyebab_primary_key_auto_increment` | AUTO_INCREMENT `t_faktor`, `t_penyebab` |
| `2026_06_09_110000_seed_public_service_kategori_tema_master` | Seed kategori–tema layanan masyarakat |
| View SQL (dump) | `DROP TABLE` + `CREATE VIEW` untuk `da_contigency`, dll. |

### Environment production

```env
REGISTRATION_DEFAULT_ROLE_ID=4
REGISTRATION_ACCOUNT_STATUS=pending
DASHBOARD_SHOW_COUNTING_RECORDS=false
```

### Isu known (import dump SQL)

- Tabel legacy dari phpMyAdmin sering **tanpa AUTO_INCREMENT** → error `Field 'id' doesn't have a default value`
- Solusi: jalankan migration di atas, atau ALTER TABLE manual
- View `da_contigency`: harus `DROP TABLE` dulu sebelum `CREATE VIEW`
