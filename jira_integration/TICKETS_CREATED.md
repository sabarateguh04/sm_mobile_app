## 📝 Manual Steps Required

### 1. Add Story Points to Each Story
Untuk setiap story DDP-816 sampai DDP-825:
1. Buka ticket di Jira
2. Click "Story point estimate" field
3. Isikan sesuai tabel di atas
4. Save

### 2. Link to Epic SM-BO
Untuk semua stories:
1. Buka ticket di Jira
2. Click "Epic Link" field
3. Pilih epic "SM-BO"
4. Save

### 3. Create Subtasks Manually
Refer to `JIRA_TICKETS_FASE_1.md` untuk detail setiap subtask:
- Copy summary dan description dari dokumen
- Create as "Task" type
- Link ke parent story dengan mention di description: "Parent Story: DDP-XXX"
- Set due date sesuai estimate
